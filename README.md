# PUG PINBALL WORLD 〜パグの世界でピンボール大冒険〜

パグの顔のボールを、パグのしっぽではじくスマホ向けピンボール（縦画面・PWA）。

## 起動方法

- **すぐ試す**：`dist/pug-pinball-world.html` を1つ開くだけで遊べます（1ファイル版。オフライン起動・ホーム画面追加は不可）。
- **PWAとして使う**：このフォルダ一式（`index.html` `css/` `js/` `icons/` `manifest.webmanifest` `sw.js`）を HTTPS のサーバーに置きます（Firebase Hosting、GitHub Pages など）。
  - iPhone：Safariで開く →「共有」→「ホーム画面に追加」
  - Android：Chromeで開く → メニュー →「アプリをインストール」
- **PCで確認**：フォルダで `python3 -m http.server 8000` → `http://localhost:8000/`
- ファイルを更新したら `sw.js` の `CACHE` 名（`pug-pinball-v1`）の数字を上げてください。古いキャッシュが残りません。
- 1ファイル版の作り直し：`node build.js`

## 操作

| 操作 | 動き |
|---|---|
| 画面の左側をタップ | 左のしっぽ |
| 画面の右側をタップ | 右のしっぽ |
| 左右同時タップ | 両方 |
| 右下の「発射」を長押し→はなす | 発射（長いほど強い） |
| 右上の Ⅱ | 一時停止 |
| PC | ← →（または Z / M）、スペース長押しで発射、P で一時停止 |

## 実装した機能

- **物理演算**：重力・加速度・空気抵抗・反発係数・壁衝突・バンパー反発・フリッパーの回転と打撃力・ボール同士の衝突・回転表現・落下判定・発射初速の調整・マルチボール。1/480秒刻みで計算し、壁抜けを防止。止まったボールの自動救出、画面外に出た場合の復帰あり。調整値は `js/game.js` 冒頭の `TUNE` と各ステージの `phys`。
- **パグの世界**：ボール＝パグの顔（回転・衝突で驚き顔・高得点で笑顔・フィーバーで星目）、フリッパー＝しっぽ（左は伸びてくるん、右はバネ揺れ）、バンパー＝肉球／顔／お尻／クッション／フード／シーサー ほか、ターゲット＝骨・ゴーヤ・まんじゅう等、穴＝犬小屋、スピナー＝回るパグ顔。
- **10ステージ＋隠し1**：街／遊園地（回転バンパー・コースター）／温泉（お湯ゾーン）／沖縄（波・シーサー・ゴーヤ・琉球音階BGM）／海底（チンアナゴ・ニシキアナゴ・トンネル）／宇宙（重力変化・ワープ）／お菓子工場（連続ターゲット・コンベア）／雪国（氷・育つ雪玉・そり）／ミステリー城（順番ターゲット・隠し扉・秘密ルート）／パグ王国（ボス）／ひみつのパグ天国。各ステージに目標（クリア条件）があり、クリアで次が解放。
- **得点・コンボ**：2コンボ×1.5、3コンボ×2、5コンボ×3、10コンボでパグフィーバー。
- **特殊イベント**：パグフィーバー、マルチボール、巨大パグボール、肉球ラッシュ、ドッグフードボーナス、隠しトンネル／ワープ、パグ大集合、ジャックポット、スーパージャックポット、エクストラボール、ボールセーブ、隠しイベント。条件は一時停止画面と設定画面で確認可能。
- **やり込み**：パグ12種、ボール8種、テーブルカスタム（しっぽ色・エフェクト・バンパー・装飾・背景）、実績22個、プレイヤーレベル、デイリーチャレンジ（毎日3つ）、バウ（ゲーム内通貨）、ローカル記録（ステージ別ベスト5・総合・履歴）。
- **その他**：操作しながら進むチュートリアル、ギミック初回ヒント、効果音とBGM（すべてWebAudioで合成。音声ファイルなし）、振動、画質設定、自動保存（LocalStorage・データ形式バージョンつき・保存失敗時の通知）、PWA（マニフェスト・オフライン起動）。
- 画像・音源はすべてこのプログラムが描画／合成するオリジナルで、外部素材・外部APIは使っていません。

## 仕様書と違う点・未実装

- **Phaser 3 / Matter.js は使っていません。** 物理は自作です。高速のボールとフリッパーで壁抜けが起きにくく、1ファイルで軽く動くことを優先しました。
- **ボーナスステージ**は別テーブルではなく、クリア後20秒の「ボーナスタイム」（落ちても戻る＋フード出現）として実装。
- **オンラインランキング**は未実装（サーバーが必要）。記録画面は「この端末だけのローカル記録」と明記。
- **リアルマネー課金**なし。
- **IndexedDB** は未使用（LocalStorageのみ）。
- **振動**は iPhone の Safari では動きません（ブラウザが非対応）。Android Chrome では動作。
- 三線BGMは合成音による「三線風」です（実際の三線の録音ではありません）。
- パグごとの違いは、毛色・小物・待機アニメーション（タイトル画面）と、ゲーム中の応援表情です。

## テスト結果

`node test/sim.js 30 0.7`（自動プレイ：全11ステージ×30ゲーム）

- 画面外への飛び出し：0回 ／ 壁・発射レーンへのすり抜け：0回 ／ 進行不能：0回
- 止まったボールの救出：全330ゲームで4回
- 全ステージでクリア達成を確認（30ゲーム中：S1 30、S2 20、S3 24、S4 8、S5 11、S6 22、S7 23、S8 15、S9 6、S10 14、S11 24）

ヘッドレスChrome（390×844・360×640のスマホ表示、1280×720のPC表示）

- チュートリアル（左→右→同時→発射）、一時停止、ゲームオーバー→リザルト→もう一度、購入、保存→再読み込み、オフライン再読み込み、サービスワーカー登録：すべて成功、JSエラー0件
- 連続66ゲーム後のメモリ：約5MBで増加なし

**未確認**

- iPhone Safari・Android Chrome の実機（タッチの感触、ホーム画面追加後の全画面表示）
- 音の聞こえ方（自動テストでは音を聞けないため、音量バランスは耳での調整が必要）
- 自動プレイは狙い撃ちをしないため、人が遊んだときの難易度は実機で要調整

## ファイル構成

```
index.html / css/style.css
js/data.js    ステージ・パグ・実績などのデータ
js/game.js    物理演算とルール（画面に依存しない）
js/art.js     パグや部品の描画
js/render.js  ゲーム画面の描画
js/save.js    セーブ・レベル・デイリー・実績判定
js/audio.js   効果音とBGM
js/ui.js      メニュー画面
js/main.js    入力・ゲームループ
test/sim.js   自動プレイ検証
```
ステージの追加は `js/data.js` の `PP.STAGES` に1件足すだけです。
